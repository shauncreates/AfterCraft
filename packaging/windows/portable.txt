AfterCraft portable mode

Place this file beside AfterCraft.exe to keep settings, shortcuts, recovery, logs and
plugin registrations in AfterCraftData beside the executable. AfterCraft.portable is
an equivalent marker. Copy the complete app folder, including helpers and runtime.

Remove both markers to use the normal per-user settings folder (%APPDATA%\AfterCraft).
If AfterCraftData is not writable, AfterCraft logs a warning and uses that user folder.
Custom disk/media cache paths set in preferences remain as configured.
