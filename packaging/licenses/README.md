# Dependency license supplements

Some published Cargo packages omit license texts. These supplements accompany the
versioned dependency inventory generated by `tools/collect-licenses.py`.
`sources.json` records the upstream source revision, direct license URL and SHA-256.
Only license documents are fetched; no implementation is copied here.

Where the published manifest explicitly offers Apache-2.0 but has no separate
license file, `DECLARATION.json` records that declaration and the standard Apache
license text is supplied. Other packages keep their own copyright notices.

The installed `licenses/rust-dependencies/inventory.json` includes versioned source
archives for registry dependencies and pinned Git source references. Unmodified
MPL-2.0 packages, including Symphonia, can be obtained from those archives under
their original licenses. This distribution does not modify their source.
